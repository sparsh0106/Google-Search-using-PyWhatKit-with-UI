# 🔍 Google Search Desktop Utility (PyWhatKit + Tkinter UI)

A lightweight desktop GUI application built with **Python**, **Tkinter**, and **PyWhatKit** that allows users to type a search query into a desktop window and launch an instant Google search in their default web browser (as well as fetch topic summaries).

---

## 📂 Repository Structure

- `google_search_with_ui.py`: Tkinter GUI search bar integrated with `pywhatkit.search()` and `pywhatkit.info()`.
- `README.md`: Project documentation.

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparsh0106/Google-Search-using-PyWhatKit-with-UI.git
   cd Google-Search-using-PyWhatKit-with-UI
   ```

2. **Install dependencies**:
   ```bash
   pip install pywhatkit
   ```

3. **Run the application**:
   ```bash
   python google_search_with_ui.py
   ```
